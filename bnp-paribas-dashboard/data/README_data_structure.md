# Template pour données BNP Paribas - Structure Power BI

## Fichiers à créer :

1. **bnp_performance_2023_2024.xlsx**
   - Onglet "PNB_Trimestriel" : PNB par trimestre et division
   - Onglet "Resultat_Net" : Résultat net évolution
   - Onglet "ROE_ROA" : Ratios de rentabilité

2. **bnp_risques_2023_2024.xlsx**
   - Onglet "Provisions" : Provisions pour risque de crédit
   - Onglet "NPL" : Non-performing loans par division
   - Onglet "Cost_of_Risk" : Coût du risque évolution

3. **bnp_capital_2023_2024.xlsx**
   - Onglet "CET1" : Common Equity Tier 1 ratio
   - Onglet "RWA" : Risk Weighted Assets
   - Onglet "Tier1" : Ratios de capital

4. **bnp_divisions_2023_2024.xlsx**
   - Onglet "Retail_Banking" : Banque de détail France
   - Onglet "Corporate_Banking" : Banque d'entreprise
   - Onglet "International" : Activités internationales

## Métriques clés à inclure :
- Dates : Trimestres 2023-2024
- PNB : Produit Net Bancaire (M€)
- Résultat : Résultat net (M€) 
- Provisions : Provisions crédit (M€)
- ROE : Return on Equity (%)
- CET1 : Common Equity Tier 1 ratio (%)
- Cost/Income : Ratio efficacité (%)

## Sources données :
- Rapports annuels BNP Paribas 2023-2024
- Résultats trimestriels publiés
- Communiqués presse résultats
